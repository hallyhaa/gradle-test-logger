# Babelserver Test Logger

> **This project has moved to [GitLab](https://gitlab.com/hallyhaa/gradle-test-logger).** This GitHub repository is archived and will not receive updates.

A Gradle plugin that provides colorful, real-time test output inspired by Maven Surefire — shows pass/fail/skip per test with error messages, groups parameterized tests, and adds an aggregated summary for multi-project builds. Supports JVM, Kotlin/JS, and Kotlin/Native.
